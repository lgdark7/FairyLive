## 4. CAPTURE ISOLATION & CREATOR UI SEGREGATION
* **Single-App Capture (Android 14+ / 15)**:
  * Uses `MediaProjection` task-isolated recording (`RECORD_CONTENT_TASK`).
  * Excludes studio controls, floating HUD, system notifications, incoming call popups, and OS navigation bars from the broadcast feed.
* **Full Screen Fallback**:
  * Available via `CaptureSource.ENTIRE_SCREEN` using `MediaProjectionConfig.createConfigForDefaultDisplay()`.
* **Creator-Only UI Absence**:
  * Selection handles, crop sliders, rotation stems, lock badges, and layer panels reside strictly in Android Canvas preview; GLES compositor renders pure content with zero editor chrome.
