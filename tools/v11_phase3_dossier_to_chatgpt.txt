# FAIRY LIVE V1.1 Phase 3: Live Browser Overlay & Dynamic Transformation Gate Dossier

**Target Milestone**: V1.1 Phase 3 ("Live Browser Overlay, Dynamic Transformations & Interactive Studio")  
**Target Device**: Google Pixel 8 AVD (`emulator-5554`, Android 15 API 35)  
**Host / Platform**: Windows 10 x64, pure Kotlin native stack  
**Date**: September 17, 2026  

---

### 1. Architectural & Verification Scope Completed

In direct alignment with the Phase 3 directive and acceptance criteria:

1. **Live Browser / Web Overlay Engine (`OffscreenWebRenderer.kt`)**:
   - Implemented an offscreen WebView rasterizer rendering web pages into high-fidelity `ARGB_8888` Bitmaps on the main looper without requiring an active View tree attachment.
   - Handles page loading lifecycle (`onPageStarted`, `onPageFinished`, error states) and transparent background rendering (`Color.TRANSPARENT`).
   - Implemented **Scroll & Crop Pipeline**:
     - `scrollX` and `scrollY` injection via `postVisualCommit` and DOM `window.scrollTo(x, y)`.
     - `CropRegion` (`cropLeft`, `cropTop`, `cropRight`, `cropBottom`) bitmap slicing to eliminate unwanted headers/scrollbars before texture upload.
   - Built a custom fallback badge in Warm Editorial styling (`#231B15` base, `#C27D48` accent) if network or invalid URL errors occur.

2. **GLES Compositor Web & Dynamic Transforms (`GlesRenderer.kt` & `OverlayCompositor.kt`)**:
   - Segregated into the `BROADCAST_COMPOSITE` rendering pipeline.
   - Offscreen Web Bitmaps are dynamically bound and updated into OpenGL 2D textures (`GL_TEXTURE_2D`).
   - Full transform pipeline applied in shaders: Normalized X, Y, Width, Height, Scale ($0.1\times - 5.0\times$), Opacity ($0.0 - 1.0$), and **Arbitrary Rotation ($0^\circ - 360^\circ$)** using vertex coordinate matrix multiplication.
   - Streamer Floating HUD (`STREAMER_HUD_UI`) remains strictly attached to the creator window decor view and **never bleeds into the broadcast composite surface**.

3. **Creator Studio Canvas & Inspector (`CreatorStudioFragment.kt` & `sheet_inspector.xml`)**:
   - Integrated `OverlayType.WEB` and `OverlayType.YOUTUBE_SUBSCRIBER` into the WYSIWYG studio canvas (`BroadcastPreviewView.kt`).
   - Drag, pinch-to-scale, and rotation gesture manipulation directly on canvas with bounding-box feedback.
   - Comprehensive Inspector Controls:
     - Target URL input (`et_web_url`) and "Load URL" button (`btn_web_load`)
     - Transparent background switch (`switch_web_transparent`)
     - Custom render resolution (`et_web_width`, `et_web_height`)
     - Fine-grained Position ($X, Y$), Scale ($S$), and **Rotation Angle ($0^\circ - 360^\circ$)** numerical inputs (`et_rotation_deg`, `btn_rotate_90`, `btn_rotate_reset`)
     - Crop region sliders (`et_crop_left`, `et_crop_top`, `et_crop_right`, `crop_bottom`)
     - Real-time Scroll offsets (`et_scroll_x`, `et_scroll_y`) and touch drag-to-scroll mode

4. **Scene Persistence (`SceneRepository.kt`)**:
   - Fully serialized `WebOverlayConfig` (`url`, `transparentBackground`, `refreshIntervalSeconds`, `customWidth`, `customHeight`, `scrollX`, `scrollY`, `cropLeft`, `cropTop`, `cropRight`, `cropBottom`) and `YouTubeSubscriberWidgetConfig` to JSON in `fairy_scenes_prefs`.
   - Verified 100% round-trip persistence across application restarts and scene switches.
