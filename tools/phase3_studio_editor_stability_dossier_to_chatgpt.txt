## 2. Detailed Technical Implementations

### A. Authoritative Gesture State Machine (`BroadcastPreviewView.kt`)
- Defined strict `GestureState` enum:
  ```kotlin
  enum class GestureState {
      IDLE, DRAG, SCALE_ROTATE, ROTATE, RESIZE,
      CROP_LEFT, CROP_TOP, CROP_RIGHT, CROP_BOTTOM, WEB_SCROLL
  }
  ```
- All touch events follow deterministic entry/exit transitions. Single-finger drag moves the body, corner handles trigger `RESIZE`, rotation stem triggers `ROTATE`, specific edge handles enter the respective `CROP_*` state, and two fingers enter `SCALE_ROTATE`.

### B. Visual 4-Handle Crop Editor & Rotation-Aware Math
- Each crop handle is drawn with an amber fill (`#F59E0B`), white border, and a subtle orientation notch (vertical for Left/Right, horizontal for Top/Bottom).
- `unrotateDelta(dx, dy, rotDegrees)` transforms screen drag deltas into the overlay's local coordinate space.

### C. Z-Order Parity & Monotonic Normalization
- `BroadcastSceneManager.reorderLayersInActiveScene` re-assigns monotonic `zIndex = (index + 1) * 5` across the active scene list on every reorder.
- Both Preview (`sortedBy { it.zIndex }`) and GLES Renderer (`layers.sortedBy { it.transform.zIndex }`) match layer order.
