STATUS: PASS ✅ (EMPIRICALLY VERIFIED ON ANDROID 15 / API 35 ENVIRONMENT)

1. EXACT CAPTURE ARCHITECTURE:
- Pure Kotlin Android Native MediaProjection + MediaCodec + OpenGL ES (OverlayCompositor). Zero 3rd-party streaming SDKs.
- Android 14+ (API 34+):
  Invokes MediaProjectionConfig.createConfigForUserChoice() when CaptureSource.SINGLE_APP is selected.
  Presents Android system screen-share consent dialog (com.android.systemui.mediaprojection.permission.MediaProjectionPermissionActivity) with mode selector spinner.
  Launches Android System App Selector ("Share or record an app", com.android.systemui.mediaprojection.appselector.MediaProjectionAppSelectorActivity).
  Android binds MediaProjection instance to the selected task window via RECORD_CONTENT_TASK.
  Zero-copy hardware surface pipeline: VirtualDisplay -> SurfaceTexture -> OpenGL ES (OverlayCompositor) -> Hardware MediaCodec H.264 Encoder (c2.android.avc.encoder).
- Fallback & Validation:
  CaptureSource.ENTIRE_SCREEN on API 34+ uses MediaProjectionConfig.createConfigForDefaultDisplay().
  API < 34 attempting SINGLE_APP displays an explicit, non-silent error alert directing creator to select Entire Screen.
  FairyStreamService initiates foreground execution with FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION with resilient fallback if microphone FGS is restricted due to background activity state.
