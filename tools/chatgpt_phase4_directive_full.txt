3. WEBPAGE SCROLLING
==================================================

Scrolling must work naturally.

Support:

- vertical scrolling
- horizontal scrolling where webpage permits it
- touch-driven scrolling
- inspector numeric scroll offsets
- programmatic scroll
- persistence of scroll position

Creator interaction must distinguish between:

A. moving the overlay itself

B. scrolling the webpage inside the overlay

Do NOT allow these gestures to fight each other.

Recommended behavior:

NORMAL MODE:
drag outside internal browser interaction area  moves overlay

BROWSER INTERACTION MODE:
tap/hold interaction control  enables webpage interaction

When browser interaction mode is active:

- swipe  webpage scroll
- tap  webpage interaction
- links/buttons  webpage interaction

Provide an obvious creator UI indicator for the active mode.
