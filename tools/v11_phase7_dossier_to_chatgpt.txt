SECTION 3: A/V SYNC INVESTIGATION SUMMARY
──────────────────────────────────────────────────────────────────────────────

Per ChatGPT Directive, we did NOT simply subtract 250 ms from video timestamps.
Comprehensive analysis in PHASE7_AV_SYNC_INVESTIGATION.md:
  1. Audio timestamps start at wallClockPtsUs ≈ 0 ms upon AudioRecord initialization.
  2. Video timestamps are generated via eglPresentationTimeANDROID on the MediaCodec input surface.
  3. On an Android emulator using SwiftShader (software GL), EGL initialization + VirtualDisplay binding takes ~280–350 ms.
  4. The first video frame is emitted at session elapsed ~300 ms, while audio has been flowing since ~0 ms.
  5. The drift rate over 40 seconds was only 46 ms (1.13 ms/s), proving that the clocks do NOT drift. The offset is pipeline initialization latency.
  6. Hardcoding a 250 ms subtraction would break physical devices where initialization is 20 ms.
