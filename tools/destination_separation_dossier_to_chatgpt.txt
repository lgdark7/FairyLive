# FAIRY LIVE — Stream Destination Architecture & Ingest Isolation Report
**Milestone:** V1.2 Production Hardening — Clear Separation of Test Ingest from YouTube Live
**Timestamp:** 2026-09-17 15:40:00 IST
**Author:** FAIRY LIVE Engineering Pairing Agent

---

## 1. Executive Summary & Root Cause Confirmation
Forensic audit of device state confirmed why `[HANDSHAKE_FAILED] 127.0.0.1:19350/live` was displayed:
1. **Stale Test Harness Artifact**: Automated local acceptance test harnesses (e.g. `tools/run_phase7_capture.py`) previously seeded `rtmp://127.0.0.1:19350/live` directly into `fairy_live_settings.xml` without an automated cleanup/restore stage.
2. **Implicit Host Fallback**: In `RtmpClient.kt`, when parsing failed or host was empty, `RtmpEndpoint.parse` fell back to `127.0.0.1:1935`.
3. **Lack of Explicit Destination Model**: The repository treated all RTMP URLs identically, without distinguishing whether the creator intended to stream to YouTube Live, a custom RTMP destination, or a local emulator test harness.

All three root causes have been eliminated with strict compile-time, repository-time, and pre-flight architectural guards.

---

## 2. Implemented Architecture Changes

### A. Enterprise StreamDestination Enum (`StreamDestination.kt`)
Created `com.fairylive.app.core.settings.StreamDestination`:
```kotlin
enum class StreamDestination(val displayName: String, val defaultUrl: String) {
    YOUTUBE("YouTube Live", "rtmp://a.rtmp.youtube.com:1935/live2"),
    CUSTOM_RTMP("Custom RTMP", ""),
    LOCAL_TEST("Local Test Server (Dev Only)", "rtmp://127.0.0.1:19350/live")
}
```

### B. Self-Healing Settings Repository (`StreamSettingsRepository.kt`)
- Added `KEY_DESTINATION = "stream_destination"`.
- **Automatic Migration & Purge**: On `loadSettings()`, if any legacy or test URL pointing to `127.0.0.1`, `localhost`, or port `19350` is discovered in SharedPreferences without `LOCAL_TEST` destination, the repository **immediately purges** it and overwrites it with `StreamDestination.YOUTUBE.defaultUrl` (`rtmp://a.rtmp.youtube.com:1935/live2`).
- Stored encrypted stream keys in `SecureCredentialStorage` are strictly preserved during migration.

### C. Zero Host Fallback in Ingest Parser (`RtmpClient.kt`)
- In `RtmpEndpoint.parse()`, removed silent fallback to `127.0.0.1`. If the host cannot be extracted or is blank, it throws `IllegalArgumentException("Invalid RTMP URL: Host cannot be empty")`, which is cleanly captured and categorized as `StreamErrorType.MALFORMED_URL`.

### D. Multi-Stage Fail-Fast Invariant Checks
1. **`StreamConfigurationValidator.kt`**:
   - Added destination-aware validation.
   - When `destination == StreamDestination.YOUTUBE` and the URL contains `127.0.0.1` or `localhost`: Rejects immediately with `Invalid Streaming Destination` and user message: *"FAIRY LIVE is configured for a local test server instead of YouTube Live. Please switch destination or update your Server URL in Settings."*
   - When stream key is blank: Rejects immediately before socket or encoder startup.
2. **`FairyStreamService.kt`**:
   - Pre-flight validation executes before launching GLES/MediaCodec pipelines.
3. **`CreatorStudioFragment.kt` & `DashboardFragment.kt`**:
   - Pre-flight validation executes **before** displaying the Android system `MediaProjection` consent dialog.
   - If invalid, an `AlertDialog` is surfaced with an **"Open Settings"** action button routing directly to Settings.

### E. User-Facing Destination Selector (`SettingsFragment.kt` & `fragment_settings.xml`)
- Added `rg_destination` RadioGroup:
  1. `YouTube Live (a.rtmp.youtube.com:1935/live2)` (Checked by default; endpoint field is locked to prevent typos).
  2. `Custom RTMP Destination` (Unlocks editable URL field).
  3. `Local Test Server (127.0.0.1:19350 - Dev Only)` (For developer automated testing).
- Stream key field is styled with masked password input and actionable placeholder.

### F. Audited Test Harness Isolation (`tools/run_phase7_capture.py`)
- Test script now explicitly injects `StreamDestination.LOCAL_TEST` during execution.
- Added mandatory cleanup in `finally:` block that restores `StreamDestination.YOUTUBE` (`rtmp://a.rtmp.youtube.com:1935/live2`), preventing test artifacts from remaining on test or creator devices.
